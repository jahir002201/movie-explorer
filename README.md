# Movie Explorer

A responsive React project for browsing and searching TV shows using the **TVMaze API**.

Built with **Vite, React, JavaScript, Tailwind CSS, and React Router**.

**API:** TVMaze — https://www.tvmaze.com/api

# Features

* Search TV shows by title
* Browse available shows
* View ratings and basic information
* Fully responsive design
* View show details in a modal

## CLI

```bash
npm install
npm run dev
```
